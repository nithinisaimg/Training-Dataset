# 📌 Overview

This repository contains multiple Jupyter notebooks demonstrating complete **Exploratory Data Analysis (EDA)** workflows.

Each notebook covers:

- Data Loading
- Data Cleaning
- Missing Value Analysis
- Descriptive Statistics
- Outlier Detection
- Distribution Analysis
- Correlation Analysis
- Statistical Visualization
- Data Interpretation

The goal is to understand each dataset before applying Machine Learning algorithms.

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/nithinisaimg/Training-Dataset.git
```

Move into the repository

```bash
cd Training-Dataset
```

Install dependencies

```bash
pip install pandas numpy matplotlib seaborn scipy jupyter
```

Launch Jupyter Notebook

```bash
jupyter notebook
```

# 📈 Exploratory Data Analysis Workflow

Each notebook follows a structured workflow:

## 1️⃣ Data Inspection

- Load Dataset
- View First & Last Rows
- Dataset Shape
- Column Information
- Data Types

---

## 2️⃣ Data Cleaning

- Missing Values
- Duplicate Records
- Null Handling
- Data Consistency Checks

---

## 3️⃣ Statistical Analysis

Including:

- Mean
- Median
- Mode
- Range
- Variance
- Standard Deviation
- IQR
- MAD
- Trimmed Mean

---

## 4️⃣ Visualization

The notebooks generate:

- 📊 Histograms
- 📉 KDE Plots
- 📦 Boxplots
- 🔥 Heatmaps
- 📈 Scatter Plots
- 📍 Q-Q Plots
- Correlation Matrix

---

## 5️⃣ Outlier Detection

Techniques used include:

- IQR Method
- Boxplot Analysis

---

## 6️⃣ Correlation Analysis

Understanding relationships between numerical features using:

- Pearson Correlation
- Heatmaps
- Pairwise Comparisons
